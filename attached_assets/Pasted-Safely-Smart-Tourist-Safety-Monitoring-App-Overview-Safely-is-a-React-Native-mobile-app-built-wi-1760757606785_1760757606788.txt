Safely - Smart Tourist Safety Monitoring App
Overview
Safely is a React Native mobile app built with Expo that helps tourists stay aware and safe by providing real-time location tracking, danger zone visualization, and emergency response features. The app uses AI + location intelligence to keep tourists connected and safe in unfamiliar areas.

Tagline: "Safety, Secured by Awareness."

Project Status
Current State: MVP Complete - All features implemented and functional
Last Updated: October 17, 2025

Features Implemented
1. Authentication Flow
Splash/Onboarding Screen: App branding with "Get Started" CTA
Login Screen: Dummy authentication (accepts any credentials)
Registration Screen: Collects name, email, phone
2. Digital Tourist ID
Blockchain-style digital ID display
Shows trip information (ID, hash, duration, status)
Static dummy data for MVP
3. Interactive Map Dashboard
Real-time location display using react-native-maps
User location marker (blue dot)
7 danger zones with varied types (polygons and circles):
Red (Restricted Zones): 2 zones with polygon and circle overlays
Orange (Danger Zones): 2 zones with circle and polygon overlays
Yellow (Shady Areas): 2 zones with polygon and circle overlays
Purple (Accident Zone): 1 circle overlay
Text labels directly on each zone showing zone type
Welcome header with user name
Bottom control panel with 5 buttons (settings, location sharing, SOS, report, alerts)
4. Panic Button (3-Click Safety)
Prominent red floating action button (SOS)
Requires 3 clicks to send emergency alert (prevents accidental activation)
Shows countdown popup: "Click X more times to send SOS"
3-second timeout resets click counter if not completed
Final confirmation: "SOS Alert Sent!" with details
5. Geofence Detection & Zone Entry Alerts
Automatic monitoring of user location every 3 seconds
Detects entry into Restricted, Danger, or Shady zones
Triggers warning alert when entering dangerous areas
Prompts user to confirm if area is still dangerous
Works with both circular and polygon-shaped zones using ray-casting algorithm
6. Report Area Status
Report button in bottom controls
Modal interface to report area status
Four report types: Shady Area, Dangerous Zone, Accident Occurred, Restricted Area
Each option color-coded to match zone types
Confirmation message after submission
7. Safety Alerts
List of dummy safety notifications
Color-coded by alert type (warning, danger, info)
Timestamps and descriptions
"Clear All" functionality
8. Settings & Profile
View and edit user profile information
Location sharing toggle (dummy state)
Alert notifications toggle
Trip information display
Trip History button to view past trips
Logout functionality
9. Trip History
Dedicated screen showing previous trip details
Map view with complete trip route (polyline)
Trip statistics: distance, duration, number of alerts
Trip Alerts list: All safety warnings received during the trip
User Reviews: Reports and feedback left during the trip
Color-coded danger zones on the route
Start and end point markers

How to Run
For Mobile Testing (Recommended)
Install Expo Go app on your mobile device:

Android - Google Play
iOS - App Store
The Expo server is running and will display a QR code in the console

Scan the QR code with:

Android: Expo Go app
iOS: Camera app (will open in Expo Go)
The app will load on your device

For Web Preview (Limited)
The app runs on port 5000 with npx expo start --web --port 5000
Access via Replit webview (note: some mobile features may not work on web)
Full experience requires mobile device with Expo Go
Development Commands
npm start          # Start Expo dev server
npm run android    # Open on Android emulator
npm run ios        # Open on iOS simulator  
npm run web        # Open web version
